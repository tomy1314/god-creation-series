# 《反派卡》模板（蚩尤输出件 v2.0 · 可复制填空 · 三档通用）

> 使用说明：把尖括号内容逐项填满，**不留空、不写「待定」**。填不满的项，说明这个反派还没想清楚，回蚩尤第 5 步重来。
> 本模板为通用件，不含任何具体作品的人名、地名、专有名词。
>
> **先定档，再填卡。** 三档共用本模板，差别只在「填到哪一节」——标【L1】的节 L2／L3 可简填，标【L3 免】的节不必填。
> **恒定四节（二 权限／三 机械破口 → 行为算法／四 语言指纹／五 行动账本）格式三档完全一致，L3 可以只填一格，但不许改结构。**

---

## 〇、基本信息（三档必填）

| 项 | 内容 |
|---|---|
| **层级** | **L1 大反派／L2 卷内 BOSS／L3 阶段阻碍** |
| 代号／称谓（对外） | <他让人怎么称呼他；不用全名也是一种设计> |
| 底层私下叫他 | <一个带情绪的绰号；体现他被怎么看待> |
| 身份／职位 | <这个世界里一个真实存在的职位，不是「邪恶首领」这种空壳> |
| 权力来源 | <谁给他的权力；他听谁的；谁能撤他> |
| 首次亮相章／正式对峙章／退场章 | <三章分置，不要把亮相和对峙挤在一章；L3 可合并> |
| 与主角的关系起点 | <认识？不认识？知不知道对方存在？> |
| **一句话存在理由** | **L1**：他让主角不能不改变___／**L2**：他让主角在本卷失去___／**L3**：他让主角在___这件事上赢了第一次 |

> 三档判定法（拿不准时用）：他退场后故事还剩下什么？**什么都不剩＝L3；剩下一卷的代价＝L2；主角被迫改变＝L1。**

## 一、镜像轴【L1 全填｜L2 填两行｜L3 免，改填标签】

| 轴 | 主角 | 反派 | 关系 |
|---|---|---|---|
| 欲望（要什么） | < > | < > | 同源／反向 |
| 恐惧（怕变成谁） | < > | < > | 同源／反向 |
| 方法（靠什么做事） | < > | < > | 同源／反向 |
| 底线（绝不做的事） | < > | < > | 同源／反向 |
| 盲区（看不见什么） | < > | < > | 同源／反向 |
| 语言习惯 | < > | < > | 同源／反向 |

**L1 要求**：至少 3 条「同源」，至少 1 条「反向」。
**L2 要求**：只需 1 条同源 + 1 条反向，且**必须落在主角本卷最依赖的那项特长上**（他专克这一项）。

**压成一句话（L1／L2 必填，全卡之锚，写不出来就重来）**：
> 一个 <动词 + 宾语>，一个 <同一动词的不同宾语>。
> 例：一个用数字**记住**人，一个用数字**删掉**人。
> L2 例：同一门手艺，他用来**杀价**，主角用来**救人**。

**L3 改填标签（三句内能被记住，填不出＝这个角色白写了）**：
> 标签：<贪／倔／假威／守旧／怕事／爱面子……> ＋ 一个记忆点动作：< >

## 二、权限红线（三档必填 · 格式统一）

### 他能做的（按程序）
1. < >
2. < >
3. < >

### 他不能做的（三个不能 · 越权即 OOC）
1. **不能** < >（原因：<世界规则第几条／制度设计>）
2. **不能** < >（原因：< >）
3. **不能** < >（原因：< >）

### 他必须走的程序（卡在哪一环）
- 出手前须 <谁批准／哪份文件／几个工作日>
- 过程中须 <留档／录音／第三人见证>
- 事后须 <上报／备案／接受复核>

> **L1**：权限取世界观内最高一档，三条「不能」必须能在世界规则原文里找到依据。
> **L2**：中权限，须写明「他受谁制约」（L1？利益同盟？上级？），以及他**能调动的资源上限**。
> **L3**：可简填，但必须写清「他管什么、不管什么」——小反派越权同样毁世界。
>
> 这一节决定他能不能「为所欲为」。**程序写得越具体，他的压迫感越真实**——读者信的不是他多强，是他多合法。

### 他凭什么有理（L1／L2 必填 · 让对手自己说出来）

- 当前凭据：<凶名（我打得过你）／官身·体系（我抓你合法）／财政·一句话（这事我说了算）>
- 他的原话：「<……>」（不解释，让他自己说）
- 下一层换到：< >（第 < > 卷）；旧层凭据作废于 <哪一场>，上一层谁改了口：< >
- **打赢了也不算（L1 必填 · 全卡只排 1 场）**：第 < > 章，主角武力占优、结论在他缺席时被写好——<谁写的、写了什么>。同卡不按换阶层数各排一场。

## 三、机械破口（本卡核心 · 三档必填 · 类型按档位取）

| 项 | 内容 |
|---|---|
| 结构性弱点是什么 | **L1**：世界观自身的漏洞／规则悖论｜**L2**：性格硬伤 或 局部制度漏洞｜**L3**：智商盲区 或 信息差 |
| 为什么是结构性的 | <不是随机失误，是他所在位置／那套规则的必然> |
| 主角怎么抓 | <用他遵守的规则反制他；具体到哪一步、用哪份文件／哪句话> |
| 触发条件 | <什么情况下这个破口才会露出来；主角要付出什么才能触发> |
| 他为什么明知而不能自补 | **L1／L2**：补了＝否定自己存在的合法性／违背授权来源／破坏他要维护的秩序｜**L3**：他到死都没意识到自己有这个破口 |

**自检（L1）**：把「结构性弱点」那一栏读一遍——如果它可以被一句「他其实很爱他的孩子」替代，那就是情感软肋，退回重做。

**越级自检（全档）**：这个破口**允许被哪一档的招数打中**？L1 的破口只能被「主角付出代价后获得的东西」触发；**L2 的招数不得直接打穿 L1**。

## 四、语言指纹（L1 全填｜L2 填三项｜L3 填一项）

| 项 | 设定 |
|---|---|
| 句式 | <陈述句为主／疑问句为主／条件句为主> |
| 单句上限 | <不超过 N 字；超过就是不祥征兆> |
| 称谓规则 | <对人怎么称呼；什么时候改用编号；什么时候直呼其名（极罕见）> |
| 禁忌词（绝不说） | < > |
| 口头习惯／重复规则 | <同一句话不说第二遍／每句必带量词／永远用被动语态> |
| 沉默怎么用 | <不答＝否定／停顿三秒＝要动手／沉默本身就是回答> |
| 情绪失控时的语言变化 | <变快？变慢？变短？只剩单字？> |

> 检验法：把他的一句台词摘出来，遮住名字——**如果分不清是谁说的，指纹没立住。**（L3 只要求「一听就知道是他」，不求多层。）

## 六、留给作者的三问

**L1（三问全答）**
1. 这个反派**赢过一次**吗？如果他从头到尾都在输，他就不构成威胁，前面的压迫全是假的。
2. 主角**有没有一瞬间认同过他**？没有认同的对抗，是打怪，不是宿命。
3. 他的退场方式，是**被主角打败**，还是**被自己的规则打败**？后者才配得上「机械破口」这个设计。

**L2（答前两问）**
1. 他有没有**自己的**诉求？（只会执行 L1 的意志＝他是一只手，不是一个人，退回重做）
2. 他有没有**赢走主角本卷的一样东西**？（一样都没拿走＝本卷 BOSS 白设）

**L3（免答）**——只核对一条：读者能不能三句之内记住他的标签？
