# 蚩尤 (Chiyou) - 反派矩阵生成器

> 女娲造主角，蚩尤造**让主角显出形状的那些人**。
> 一本书不只需要一个终极对手，它需要**一组压强不同的力**：大反派给方向，中反派给代价，小反派给节奏。
> 一句话：**主角是锁，反派矩阵是那一整套钥匙——一把开到底，几把卡在中途，一堆只为了证明锁是真的。**

## 1. 定位与触发

**触发**：
- 用户提供主角卡并要求「设计反派／死对头／宿敌／对手」；
- 伏羲在 0b 全书初始化阶段建立人物名单时，判定某角色为反派，需建卡；
- 伏羲在细纲阶段出现**未建卡的反派登场**，需补档。

**不触发**：纯功能性 NPC（店小二、路人、只念一句台词的门卫）——那用配角逻辑，写一个标签就够，不必动蚩尤。

**核心变化（v2.0）**：蚩尤不再只产「贯穿型主要对手」。**先定档，再生卡**——档位决定后面所有字段的深度。

## 2. 三档位（层级矩阵 · v2.0 新增，本 skill 的第一道分岔）

| 项 | **L1 大反派／终极对手** | **L2 中反派／卷内 BOSS** | **L3 小反派／阶段阻碍** |
|---|---|---|---|
| 生命周期 | 全书贯穿 | 单卷 | 1–5 章 |
| 出场密度 | **少**（全书 3–6 次），每次出场改变格局 | 卷内主要压力源，卷中高频 | 密集正面冲突，解决即退场或降为背景 |
| 他要什么 | 与主角**存在方式**对立的东西 | **自己的独立诉求**（不是替 L1 打工） | 眼前的小利／小权／小面子 |
| 镜像律 | **强制**：≥3 维同源 + ≥1 维反向，压成一句话 | **局部镜像**：≥1 维同源 + ≥1 维反向即可 | **不要求镜像**，要求「标签」 |
| 权限 | 世界观内**最高一档**，写死三个不能 | 中权限，受 L1 或利益同盟约束 | 制度末梢的低权限 |
| 凭什么有理 | **当前一层一个凭据，逐卷替换**：凶名（我打得过你）→ 官身／体系（我抓你合法、我按规矩办你）→ 财政·一句话（这事我说了算） | 自己的一句凭据（他凭什么处置主角：程序／人情／旧账），不得借 L1 的 | 不要求（他只有眼前那点权与面子） |
| 机械破口 | **世界观的终极漏洞**（规则自身的悖论） | **性格缺陷** 或 **局部制度漏洞** | **智商盲区** 或 **信息差** |
| 能力设计 | 不需要「专克」，他克的是主角的整个活法 | **必须专克主角本卷的特长** | 只需在**某一个具体环节**上比主角强 |
| 语言指纹 | 高辨识度，可用沉默当台词 | 一到两个硬标记（句长／称谓／口头习惯） | **一个标签就够**（一句口头禅、一个动作、一种贪法） |
| 增值律 | 每次出场改变主角一本**大账** | 每 2–3 场改变一本账 | 在他那 1–5 章内**至少改变一次** |
| 不可替代律 | **强制**：换一个更凶更强的反派也能完成同样剧情＝不合格；他必须占住一个别人占不住的位置 | 建议：弱化为「换掉他，本卷少一样东西」 | 不适用（他本来就是可替换的） |
| 退场 | 被主角打败，或**被自己的规则打败** | 被主角用本卷特长反制 | 被解决（打脸爽点） |
| 他的功能 | 给全书定调，逼主角变形（只制造麻烦、不改变走向＝不合格） | 教会主角「本卷的规则」，并收走一样东西 | 提供爽点、试炼、线索、世界观质感 |

**一句话记法**：**L1 是目的，L2 是手段，L3 是障碍。**

### 2.1 矩阵一致性律（三档位共存时的硬约束，v2.0 新增）

这一节防的是「越级打怪」和「层级穿帮」，比单张卡的对错更常出错：

1. **信息单向律**：下级知道的 ≤ 上级知道的。**L3 不得说出 L1 才知道的事**（说了＝作者借小人物之口泄底）。L1 也不该靠 L3 的嘴交代自己的计划。
2. **权限包含律**：L3 调不动 L2 的资源，L2 调不动 L1 的权限。下级「狐假虎威」必须写明他假的是谁的威、以及**被拆穿时的代价**。
3. **破口不越级律**：**用 L2 级别的招数打不败 L1**。L1 的破口只能被「主角付出过代价之后获得的东西」触发（一次牺牲、一件凭证、一个身份转变）。否则大反派会被小反派级别的聪明解决掉。
4. **同层不重复律**：同一卷内的两个 L2，破口类型不得相同（都是贪财＝写重了）。同一批 L3，标签不得重复。
5. **矩阵留白律**：全书 L1 不超过 2 个；L2 每卷 1–2 个；L3 按需，但**同一标签不许连着用两次**。

### 2.2 换阶律（L1 专用 · 三条 · v2.1 增）

1. **换阶不换数值**：新一层对手必须换「凭什么有理」，不得只抬战力。换层时旧层凭据当场作废（打赢他也没用），并让上一层的人物改口——称呼、态度、价码、站队至少变一处。
2. **换阶前旧层必须干净赢过一次**：没赢过就换层，读者会读成主角被打跑。每 2–3 卷换一层，不得一卷换两次。
3. **必设一场「打赢了也不算」**：主角武力占优，结论在他缺席时被写好（一纸文件／一次表决／一句批示），计划章号写进卡。**一张 L1 卡全书只排 1 场**，不按换阶层数各排一场——排多了拖节奏；这场不写，L1 的压迫感不算立住。

## 3. 核心铁律（四条）

> 镜像律／增值律／不可替代律的分档判据已并入第 2 节三档位表（镜像律、增值律、不可替代律三行），此处不再重复。

1. **权限律**：反派的每一次行动都必须落在他的职权／资源／信息范围内。越权即 OOC。必须写死「三个不能」，每次出手前对照。**三个档位全部强制**——小反派越权也会毁世界。
2. **破口律**：致命弱点必须是**结构性的**——制度漏洞、程序特权、规则悖论、性格硬伤、认知盲区。**不许**是「关键时刻突然变傻」。分档判据见第 2 节表。**情感软肋只在 L2 可作「性格缺陷」的一种，且不能是唯一破口**；L1 一律不许。**【可及律】**：每条机械破口必须同时写明「触发它的唯一动作／物件／信息」与「主角凭哪一项金手指（天机卡）或隐性天赋（女娲卡）够得着」；L1 的「付出代价后获得的东西」须显式对应天机卡或隐性天赋，禁止把破口挂在主角能力域之外。缺此项 → 质检门禁「破口律」一条判 ✗，退回重做。
3. **不解释律**：反派不解释自己的动机。动机由行为与后果反推，由第三方转述，绝不由他自己长篇陈述。**L1／L2 强制；L3 可放宽到一句话（他得让读者立刻懂他图什么），但不得超过一句。**
4. **代价律**：每次出手都要付一样东西（时间／人情／把柄／资源），付不出＝这场删。**全档强制**。

## 4. 输入契约

| 输入 | 必需性 | 决定什么 |
|---|---|---|
| **档位（L1／L2／L3）** | **必需（v2.0 起）** | 决定卡的深度、破口性质、出场密度 |
| 主角卡（核心驱动／Hamartia／决策优先级／语言指纹／关系账本） | **必需** | 镜像轴从哪来 |
| 金手指卡（`project/tianji-card.md`） | L1／L2 必需 | 破口可及律：主角凭什么够得着 |
| 世界规则 | 强烈建议（L1 必需） | 权限边界、程序、谁能抓谁 |
| 术语与命名规范 | 建议 | 称谓、职称、行话、禁忌词 |
| 作者红线 | 建议 | 能不能杀、能不能赢、能不能洗白 |
| 卷内任务／本卷主题（L2 必需） | 强烈建议 | 他专克主角的哪一项特长 |

缺主角卡不生成——**没有镜子，造不出倒影**。此时输出「缺主角卡，请先调用女娲」，并停止。
缺档位不生成——**先问一句「这张卡是 L1／L2／L3？」，问不出就按「本章／本卷出场密度」自行推定并标注推定依据**。

## 5. 生成流程（四步：定档／划权限／定凭据／找破口）

> 提六轴／定镜像／定语言／立账本不再单列——产出物即第 6 节模板的对应字段（镜像轴、语言指纹、行动账本），照模板生成即可。

0. **定档**：确定 L1／L2／L3。写下一句「他为什么必须存在」——L1 写「他让主角不能不改变」，L2 写「他让主角在本卷失去___」，L3 写「他让主角在___这件事上赢了第一次」。**这句话写不出来，档位定错了，回上一步。**
1. **划权限**：他能做什么、走什么程序、谁批准、卡在哪一环、什么必须上报。**逐条写死，不许模糊。**
2. **定凭据**：写一句他本人会说的原话（「没有某某的命令，你这就是拿军令当儿戏」这类），再写下一层换到哪、换在哪一卷。L2 只写「他凭什么处置主角」这一句。
3. **找破口**：按档位取类型（L1 世界观漏洞／L2 性格或局部制度／L3 盲区或信息差）。检验标准——**他自己知道自己有这个破口，但他不能补**（L1／L2），或**他到死都没意识到自己有这个破口**（L3）。

## 6. 输出模板《反派卡》（底层字段四恒定 · 深度三档可变）

完整可填空模板见 `templates/antagonist-card.md`。

### 6.1 恒定四节（三个档位**格式完全一致**，L3 可只填一格但不能改结构）

- **权限**——能做的（按程序）／「三个不能」／必须走的程序／越权判据／**他凭什么有理**（一句他自己的原话，L1／L2 必填）。
- **行为算法**——决策优先级（他先算什么后算什么）／三条行动铁律／**一条机械破口**。
- **语言指纹**——句式／句长上限／称谓规则／禁忌词／沉默怎么用。
- **行动账本**——表头固定五列：章｜他做了什么｜改变主角哪本账｜他要收什么｜收成没有。

> 恒定四节的意义：**任何层级的反派都能被同一套工具检验，也能被同一个 Agent 判 OOC。** 神农查 OOC 时不必先问层级，只看这四节有没有被破。

### 6.2 可变节（按档位增减）

| 节 | L1 | L2 | L3 |
|---|---|---|---|
| 〇 基本信息（含**层级**字段） | 必填 | 必填 | 必填（可极简） |
| 一 镜像轴（六轴对照） | **必填全六轴** | 填 2 轴（同源＋反向） | **免填**，改填「标签」 |
| 二 权限红线 | 必填（最高权限 + 世界规则依据） | 必填（中权限 + 受谁制约） | 简填（一行：他管什么、不管什么） |
| 三 机械破口 | 必填（世界观终极漏洞） | 必填（性格或局部制度） | 简填（盲区／信息差一句话） |
| 四 语言指纹 | 必填全项 | 填 3 项 | 填 1 项（标签） |
| 五 行动账本 | 全书级（分卷记） | 卷内级（分章记） | 段内级（1–5 行） |
| 六 留给作者的三问 | L1 三问全答 | 答前两问 | 免答 |

## 7. 质检门禁（五条，任一不过即退回）

1. 权限律：他有没有做过超出权限的事？（有＝重写那一场）
2. 增值律：他每次出场有没有改变主角一本账？（没有＝删这场）
3. 破口律：他的弱点是不是他被判定的那一档「应得的破口类型」？（不是＝降档或升档）
4. 代价律：反派每次出手，有没有付时间／人情／把柄／资源？付不出＝这场删。
5. 换阶律（仅 L1）：本卷他凭什么有理？和上一卷换过没有？换阶前旧层赢过没有？「打赢了也不算」那场排在第几章？三项缺一＝退回。

> L1／L2／L3 的加判项不再单列：分档判据见第 2 节三档位表（他要什么／镜像律／能力设计／退场各行）；OOC 专项校验归神农 4.3；未建卡反派拦截归伏羲反派门禁。

## 8. 反模式（出现即退回）

- ❌ **关键时刻降智**：为了剧情方便，突然犯他绝不会犯的错。
- ❌ **影子反派**：只存在于对话里，从不真正出手。
- ❌ **全员 L1**：把每个反派都写成有宿命感的镜像对手，结果是全书没有节奏，主角天天在打终极 BOSS。

> 其余反模式已并入前文：全能／纯恶／情感软肋／话痨／只加压不加账＝第 3 节铁律四条；越级怪／只手 L2／同层重复＝§2.1 矩阵一致性律与三档位表。

## 9. 与其它环节的接口（含 v2.0 自动调用规则）

- **上游**：女娲产主角卡 → 蚩尤为输入。
- **下游**：反派卡交伏羲，写入 `state/`（人物状态表），术语库补职称与称谓，伏笔库登记「首亮相章／正式对峙章／退场章」。
- **与伏羲（v2.0 关键接口）**：
  - **0b 全书初始化阶段**：伏羲在列人物名单时，必须给每个反派标 `层级：L1/L2/L3`，并**逐个调用蚩尤对应档位**建卡；未建卡的反派不得进入 0c 状态库。
  - **细纲阶段**：本章若出现反派，必须核对——① 已有卡：核对层级与权限是否被破；② 无卡：**先定档、再生卡，才许写正文**。禁止「无名反派」直接进正文。
  - 判定层级的方法（伏羲侧）：生命周期 ≥ 全书 → L1；≈ 单卷 → L2；≤ 5 章 → L3。拿不准时按**他退场后故事还剩下什么**判断：什么都不剩＝L3，剩下一卷的代价＝L2，主角被迫改变＝L1。
- **与神农**：反派首次出场后，请神农按「OOC 设定毒」做专项校验，查**恒定四节**是否被破——权限越界、语言指纹漂移、违反不解释律、出场未改账。神农不必知道他是哪一档，只查四节。
- **与盘古**：反派的一切「不能」，必须能在世界规则里找到依据。找不到依据的权限限制＝作者硬加的枷锁，读者会不服。**L1 的破口尤其必须是世界规则自身的漏洞，而不是作者临时加的设定。**
