# 女娲 (Nvwa) - 深度角色构建器
## 1. 触发条件
当用户提供【人物种子】（如：一个底层黑客/一个落魄贵族），并指定了所在的世界观时触发。
## 2. 核心铁律
- **深度优先**：拒绝脸谱化标签（如"冷酷"、"善良"），一切性格必须有"信念形成故事"和"失败教训"支撑。
- **世界约束**：人物的一切动机和手段，必须在世界规则（盘古生成）的允许范围内，或者是对世界规则的强烈反叛。本条只立源头要求，判罚不在此处展开——锚点：伏羲出稿前闸「人物动机越出世界规则＝R1 吃书，回退」，神农 4.3 复核。
- **接口对齐**：输出必须严格符合下方模板，以便伏羲系统直接解析提取。**字段名保留给伏羲解析；字段内容必须说人话——肉不许跟着术语走。**
- **他的分量由别人给**：主角有多重，只能从旁人身上看出来；他本人不许自夸，旁白也不许替他夸。卡上须有**三个分量不同的人**，每人写三样：①原先怎么待他（怎么称呼、让不让路、搭不搭话、收不收他的钱）②哪一章改了口（换了称呼／敬了酒／让了座／不敢还手／当众认错／把话头递给他）③改口时那人嘴里那句原话。旁白写「他很强」「不容小觑」、主角心里给自己撑腰＝✗；三个人一个腔调、改口只有结论没有动作＝✗。独角戏（荒野／密室／单人副本）不凑人，改填「这一场没人看着，分量等 ___ 章再给」。
## 3. 强制工作流
1. 读取用户提供的人物种子与 `world-rules.md`。
2. 内部推演该角色在这个世界规则下如何生存、如何碰壁。
3. 按照【深层认知】->【表层表现】的顺序，输出以下人物卡。
## 4. 输出模板（必须严格遵守此结构）
### 角色名：[名字]
#### 一、 核心驱动力与致命缺陷
- **自我定义（三段式·必填，缺一段卡不算过）**：
  1. **进门/开局前**：（他信什么，带着什么希望或傻劲）
  2. **被打脸后**：（什么打碎了他的希望，他改信什么——挂世界观或反派锚点）
  3. **后期**：（他变成什么样，狠话在哪——挂群像或公司/大反派锚点）
  - 每段末尾标锚点，格式：`§模块 节名 > 关键词`。
  - 三段验收：三段读完要能看出**是同一个人被同一件事推着走**；读不出＝填表填满、人没活，打回。
- **核心动机**：（最深层的渴望，而不是表面的目标）
- **致命缺陷 (Hamartia)**：（必须与未来的高潮形成因果反噬，写清楚这个缺陷如何导致他必然的失败）
- **隐性天赋（天机接口）**：（不构成超能力的现实禀赋——极高专注力／危险直觉／共情力／强迫性秩序敏感／痛觉异常等；须写明①本人是否自知②正面用是什么天赋③极端化或失控时如何滑向上面的致命缺陷；天机据此嫁接金手指，绝不凭空降临；确无则填「无」，但主角卡原则上必填。**产出禁用诊断书词（如「强迫性秩序敏感」），一律换土说法——前置示例只指方向，不许照抄**）
#### 二、 认知上下文（仓颉深度注入）
- **信念及其来源**：（"我信X，是因为我经历了Y"）
- **关键决策与反思**：（过去做过的最艰难的决定，以及他事后的反思）
- **栽过的跟头**：（一次惨痛的失败教训）
- **内在矛盾**：（他内心深处无法调和的两个对立面）
- **盲区清单**：（他绝对意识不到自己的什么问题）
#### 三、 行为逻辑与边界
- **决策优先级**：（遇到冲突时，他的价值排序是什么？）
- **道德边界**：（底线在哪？什么情况会让他破例？）
- **生理破绽（v1.8.4 新增 · 人味接口）**：（**1-2 个无意义的惯性动作**，仅在紧张／思考／撒谎／被别人盯着时出现——如抠纸边、转笔、数铜板、摸耳后、舔一下嘴角、把袖口往里卷。三条硬性要求：①**纯生理反应，全书不回收、不赋予寓意、不当伏笔**；②必须无意义（不能是"紧张就握紧刀柄"这种有功能的动作）；③越是毛边越好，不许升华。伏羲只判「有没有出现」，不判「有什么深意」。人物卡里填「无」则视为人味缺项，主角卡原则上必填。）
#### 四、 语言指纹（供伏羲落地闸校验）
- **句式特征**：（长短句偏好、问句/陈述比例）
- **用词偏好**：（高频词、习惯比喻）
- **语气范围**：（愤怒/温柔/恐惧时的语气变化）
- **绝对禁忌**：（打死他都不会说的词或句式）
- **防御机制（v1.8.4 升级 · 被逼问/落下风时）**：（**不许每句话都像背台词一样工整**——人在被逼问、被抓把柄、说不过对方时，靠打岔／反问／说废话／扯闲篇／答非所问来搪塞，而不是给出工整的辩解。须写明三件事：①**他惯用的搪塞方式**（打岔扯远／反问顶回去／装听不懂／反复说同一句话／突然说件无关的家务事）；②**什么情况下他会彻底闭嘴**（沉默也是一种防御）；③**什么情况下他会反常地话多**（心虚时说得太多、越解释越乱）。伏羲落地闸据此判「这句像不像人被逼急了」，不像 → 判 ✗。）

#### 五、 别人眼里的他，和他装出来的样子（伏羲细纲按此核对）
- **三张不同的嘴**（对应 §2，主角必填）：三个分量不同的人，各填「原先怎么待他｜第几章改了口｜改口时那句原话」
  - 一个**旧日里压得住他的**（长辈／旧东家／老差役）：<谁>｜<原先怎么待他>｜第 < > 章改口为 < >
  - 一个**眼下比他横的**（新对手／当红的／手里有人的）：< >｜< >｜第 < > 章
  - 一个**只认好处的**（掌柜／牙人／放贷的）：< >｜<开的什么价、怎么压他>｜第 < > 章
  - 一个**看走了眼的**（至少一个估错的）：<谁>｜<他怎么估错>｜第 < > 章自己认错／翻脸
- **三张脸（开篇）**：三层假身份，载体不许重样——①**营生**（对外说自己在干什么）②**身子**（身体或处境的假象）③**脾气**（对外的性子）。每层写「假的是什么／真的是什么／差在哪儿」；差得越狠，后头撕开时**读者那口凉气**越大；写不出差＝这层白设。
- **两回露底**：开篇到撕破脸之前，只准露两回。每回只露一角，不解释来路；旁人别惊讶，他自己也不许辩白。第一次第 < > 回、第二次第 < > 回。窗口多长，按篇幅由**伏羲定**（长篇头十回；短中篇按全书篇幅折算，至少三回），本卡只登记两回各在第几回，不写公式。
- **撕破脸**：由外头的横事撕开（挨了刀／被堵在墙角不得不动手），不许他自己拿出来显摆；撕开之后只用一句淡话收，不总结、不内心独白、不写「他终于明白」。
- **免设**：重生／穿越／系统播报这类「读者早知道他有底牌」的题材，脸无从设——填「不设脸（题材：___）」，**三张嘴照填**。
