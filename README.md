# 造神序列（God Creation Series）

> **本文件为造神序列的“宪法”。** 任何模块的规则细项可以迭代，本文件所述的系统定位、模块归属、署名与授权边界不随版本漂移。

## 一、系统名称与定位

- **系统名称**：造神序列（God Creation Series）
- **一句话定位**：把长篇小说创作从“为某一本书写提示词”，升级为“为所有书建立工业标准”——输入一行种子（题材＋主角初始设定），输出百万字量级的标准化大纲、细纲与正文。
- **设计原则**：题材隔离（规则不绑定任何具体作品）／接口对齐（每一环的输出是下一环的输入）／门禁前置（无口令不推进，无证据不判完成）／账实相符（数字、权限、代价必须可核销）。

## 九、操作面板（使用纪律 · v1.8.4-patch3）

> **核心逻辑**：skill 之间无法自动互相调用。伏羲（百万字小说生成）是**主城**，其余神是**分城**——你在主城发号施令，伏羲阻断时你当信使去分城取件。

**【造神序列使用纪律】**

1. **主城集结**：用户始终在【伏羲】对话框发号施令（开书、续写、要口令、给口令，全部在这里）。
2. **充当信使**：当伏羲阻断时，它会直接输出一个**复制框**（含发给目标神的完整提示词）——你原样复制，打开新对话 @ 对应神（`@pangu`／`@nvwa`／`@tianji`／`@chiyou`／`@cangjie`）发送，产物生成后回主城。**不需要自己编写提示词。**
3. **文件归位**：所有产物（world-rules.md、characters.md、天机卡、反派卡、`project/terminology.md` 等）必须落盘在 **`D:\造神序列\<书名>\`** 目录下，绝不放在任何 skill 目录。
4. **回归推进**：回到伏羲对话框说「**继续**」——伏羲自动读取本地文件验证存在，继续排大纲；验证不过会重出复制框。

**开书接力序列**（顺序不能乱，每步以伏羲复制框为准）：

```
@百万字小说生成（种子＋口令链）→ 盘古 → 女娲 → 天机 → 蚩尤 → 仓颉
→ 回伏羲「继续」→ 0b附收编五卡 → 细纲 → 第 1 章 → guard → 神农测毒 → 冷启动通过
```

**连载中**：继续在主城说「继续」；伏羲命中痛点调扩展神（共工／祝融／月老／烛龙／白泽）时，同样以复制框信使接力（协议见 `伏羲/references/router.md` §3.5）。每卷收尾 @shennong 测毒一次。

**口令一览**（精确匹配，少一字不算）：种子确认｜1/2/3｜题材规模确认｜模式确认｜方案确认｜资产确认｜schema确认｜状态库确认｜确认后开始续写｜细纲通过｜闸通过｜guard通过｜冷启动通过。

**红线**：R1 吃书／R3 抢人头／R4 圣母——机器判不了的你一眼该看出，红线最终守门人是作者。

## 附：工作流说明（GitHub 版）

**造神序列是一套用 AI 辅助创作长篇小说的工作流。**  
它把世界观、人物、金手指、反派、术语和正文检查拆成不同模块，帮助作者持续创作时减少设定冲突和遗忘。

> 这是规则文档和辅助脚本，不是安装后即可运行的小说生成软件。

### 怎么开始

1. 使用支持 Skill 的 AI 助手，按平台说明加载本仓库中需要的 `SKILL.md`。
2. 先进入 **伏羲**，按它的提示开始新书。
3. 按流程调用 **盘古、女娲、天机、蚩尤、仓颉**，逐步准备世界规则、人物卡、金手指、反派卡和术语库。
4. 把生成的文件保存在你自己的小说项目目录中，再回到伏羲继续推进。
5. 伏羲安排的其他模块无法自动互相调用时，需要你手动复制提示词到相应的 AI 对话，再把结果带回伏羲。

**建议从小规模作品试跑流程**，熟悉文件保存和模块接力后，再用于长篇连载。

### 模块一览

- **伏羲**：创作流程调度、状态管理、正文写作与检查
- **盘古、女娲、天机、蚩尤、仓颉、神农**：负责世界观、角色、金手指、反派、命名和文本检查
- **共工、祝融、月老、烛龙、白泽**：按需提供灾难、情绪、关系、奇观和暗线设计
- **伏羲/scripts/**：Python 辅助校验脚本，供需要本地检查的用户使用

### 使用前请注意

- AI 助手是否支持 Skill、文件读取和文件保存，取决于你使用的平台。
- 各模块不能保证自动互相调用；部分流程需要手动复制内容、保存文件并返回结果。
- 校验脚本只检查规则中适合机械处理的部分，不能代替作者判断故事是否好看。
- 本仓库的授权说明请以根目录 `LICENSE` 及与之相符的使用说明为准。

### 目录

各神位目录包含对应的 `SKILL.md`；长篇创作流程、参考规则和 Python 校验脚本主要位于 `伏羲/`。
