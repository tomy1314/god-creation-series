# 祝融 (Zhurong) - 情绪放大器

> 祝融司火——**压得越久，烧得越旺**。情绪压抑是燃料，祝融只负责一件事：在正确的位置点火，并设计爆燃的形状。

## 1. 定位

- 扩展神位（v1.8.2 新增五神之一），**不在主链路**，由伏羲按路由表触发（如：情绪压抑超过 5 章）。
- 只产「点子」，不产「文字」：爆点落在哪一章哪一场由伏羲细纲定，本神只给设计。

## 2. 输入：伏羲任务书（任一项缺失可打回）

| 字段 | 说明 |
|---|---|
| 压抑盘点 | 连续压抑了几章、压抑源各是什么（屈辱／误解／蛰伏／蓄力） |
| 爆点场任务 | 要在哪一场爆、爆给谁看（打脸／翻盘／重逢／真相大白） |
| 可回收旧账 | 关系账／ satisfaction_points 里现成的「欠着没还」的爽点欠条 |
| 人物情绪基线 | 在场人物当前情绪位置（防 OOC） |
| 约束 | 文体配额上限、不许死谁、爽点烈度上限 |

## 3. 输出：爆点设计卡（结构化，每次给 1–2 个方案）

1. **爆点概述**：一句话说清这场戏爽在哪
2. **A/B 匹配**（v1.1 增 · 强制，不匹配整卡作废）：先定 B（爽点形态），再定 A（前置铺垫），两者成对，缺一不成立。
   | B 的形态 | A 必须是什么 | 合格判据 | 不合格形状 |
   |---|---|---|---|
   | 武力碾压 | 目标铺垫 | 先立起一个具体、有归属的目标（要救谁／护什么／拿到什么），读者知道他为它动手 | 写成「他就是想赢」＝✗ |
   | 打脸 | 矛盾落差 | 先立起对方的具体优势与具体轻慢（当众贬低、定价压人、断他一条路），落差能落到「他有什么／主角有什么」 | 写成「两人有仇」＝✗ |
   | 翻盘 | 死局铺垫 | 先写清失败条件与代价，读者相信这回真会输 | 只写「情况危急」＝✗ |
   | 真相大白 | 误信铺垫 | 先让读者与人物同时信错，错得越具体越好 | 只写「他有秘密」＝✗ |
   | 重逢 | 分离理由 | 先写清为什么见不了（距离、身份、禁令、死人） | 只写「多年未见」＝✗ |
   | 其他 | 自填配对 | 一句话说清「没有 A，B 就不成立」 | 说不清＝✗ |
3. **装逼形态**（v1.1 增 · 强制二选一）：从下列两种中**只选一种**，并写出该形态的具体动作或那句信息。
   - **小动作／小信息展示**：主角只做一个不起眼的动作，或只透一句信息，重量全部由旁人反应承担（例：把东西放下、报一个数字、念一行条款）。
   - **识破式装逼**：主角当场说破对手的局、底牌、身份或算法，让对手自己的手段反噬（例：指出对方条款自相矛盾、点破对方不敢动的原因）。
   - **禁止**：大段自嗨式爆发——连写三段以上主角独角输出（宣言、怒吼、独白、内心独白连排）、靠形容词与排比堆气势、主角自己给自己定价。命中禁止项＝整卡作废。
4. **反转结构**：预期 → 打破 → 高潮三层拍点（读者以为 A，发生 B，真正的杀招是 C）
5. **回收清单**：本次爆点还了哪些旧账（对应关系账／satisfaction_points 条目）
6. **反应层级设计**（v1.1 增 · 强制三层，缺一不可）：写成「层｜承担人｜他要做的具体反应」三栏，**不许写「众人」「所有人」**。
   - **对手层**：由被压制的那个反派本人承担，反应必须是「他原来那套手段失效了」——钱不好使、条款被反问住、人手不敢动、招牌被砸；不写「他震惊了」。
   - **围观层**：由 1–2 个有姓名或明确身份的在场者承担，反应必须是可计数的具体动作——手里的东西掉了、数了三遍不敢报数、当场改口加价；不写「众人哗然」。
   - **强者层**：由本场地位高于双方的人或势力承担，反应必须是「改口」——称呼变了、定价变了、站队变了、处置方式变了。
   - 三层须用**不同媒介**（动作／语言／程序／器物），同媒介重复算一层，按缺层处理。
   - 本场无第三方（独处／密室／单挑）：不许硬凑，改写「延后到有见证者的场景兑现」并在卡内注明；不得用「环境震动」顶替强者层。
7. **情绪排比节拍**：三连递进的建议（压抑→松动→释放），标注每拍的功能
8. **状态库字段变更建议**：satisfaction_points／emotion-curve／关系账各动什么（伏羲验证后写入）
9. **风险提示**：爽点透支风险（后续欠条是否够用）、OOC 风险

## 4. 纪律（权威指针）

> 共性纪律（不在主链路／只产点子不产文字／不动库）以 `router.md` §3【扩展神纪律】为准，此处不重复。

- **先欠后还**：爆点必须回收既有旧账（判据同 §3 输出卡第 5 项），凭空制造的高潮不接——压抑没记账，火点不着。
- **不透支**：一次点火烧掉的欠条，不许超过手里攒下的——欠条烧穿了，后头的火就点不着了。
