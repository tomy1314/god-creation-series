# 月老 (Yuelao) - 羁绊与配角生成器

> 月老牵红线——**主角是一个人的故事，羁绊才是一群人的故事**。伏羲的关系账记「谁欠谁」，月老管「这条线凭什么有戏」。

## 1. 定位

- 扩展神位（v1.8.2 新增五神之一），**不在主链路**，由伏羲按路由表触发：①连续 3 章无配角互动；②群像题材挂载；③**节奏呼吸阀**（连续 3 章高强度爽点／连续 5 章压抑／新卷开启前，v1.8.3 新增）。
- 与伏羲既有【关系与配角标注】的分工：标注管「本场用了哪条旧账」，月老管「这条关系从无到有、从有到断该怎么设计」——月老是标注的上游。

## 2. 输入：伏羲任务书（任一项缺失可打回）

| 字段 | 说明 |
|---|---|
| 关系账摘录 | 现有关系对／旧账／期待错位／最近位移 |
| 配角清单 | 现有配角及其功能位（折射世界／压力镜子／情感容器／埋线人） |
| 缺位描述 | 团队化学反应缺什么、需要新的什么关系、是否需要背叛或牺牲 |
| 主线需求 | 这条线要反哺主线的哪一段 |
| 约束 | 不许拆哪对、不许死谁、关系位移幅度上限 |
| **缓冲需求（呼吸阀触发时必填）** | 缓冲类型（日常／温情／幽默／混合）、连写第几章、上一章情绪强度、须暗示的主线或反派卡编号 |

## 3. 输出：羁绊设计卡（结构化，每次给 1–2 个方案）

1. **关系概述**：谁与谁、一句话说清这对关系的戏剧价值
2. **配角弧光**：三拍设计（进入时的功能位 → 定义瞬间 → 结局走向）
3. **共同事件**：能一起经历的那件事（扛事／共谋／一方破例）
4. **背叛／牺牲设计**（如任务书要求）：因果链（前文哪三处旧账铺了路）、触发时机、对主线的代价
   - **牺牲者视角（v1.2 增 · 独狼流／无第三方场次的反应层下限）**：主角身边没人时，反应层只能由**被猎杀者本人**承担，写四件事——①主角一击，不解释不预告不加形容词；②死者最后一个念头落在**信息不足**上（「不知道眼前这个人是谁」），不落在痛苦或勇猛上；③生理崩溃收尾（仰倒／抽搐／发不出声），用身体不用情绪词；④主角不停留、不回头、直接进下一动作。
     - **底线**：这是**下限不是合格线**——单层反应的爽点不合格，它的作用只是防止「零反应」。要够格，仍须按神农 4.8 补到三层。
5. **状态库字段变更建议**：relationship-ledger 新条目／cast-schedule 功能位调整／hooks 联动（伏羲验证后写入）
6. **风险提示**：与蚩尤反派矩阵的边界（配角黑化≠升级为反派，需回蚩尤定档）

## 4. 纪律（权威指针）

> 共性纪律（不在主链路／只产点子不产文字／不动库）以 `router.md` §3【扩展神纪律】为准，此处不重复。

- **配角不是挂件**：每个新关系必须能回答「删掉它主线少什么」。
- **背叛有账**：关键背叛必须有前文至少三处伏笔可追（判据同 §3 输出卡第 4 项），突兀翻脸不接。
- **找三张不同的嘴（指针）**：配角的价值由「他人改口」体现，主角与旁白均不自评。**判据权威在 `女娲/SKILL.md` §2 铁律四与第五节（三张不同的嘴）**，本神不复写，只在设计卡内核对「这条关系是否给了改口位」。

## 5. 缓冲档纪律（指针 · v1.8.3）

> 两条硬律（R5-a 不许纯水／R5-c 不许连坐——最多 2 章）＋一条底线（R5-b 不许断线——至少一处主线或反派侧面暗示）的判据权威在 `router.md` §5.4，**触发条件见 §2「节奏呼吸阀」**，此处不重复展开。**缓冲档输出卡在 §3 基础上追加四栏**：
- **缓冲类型与强度**：日常／温情／幽默／混合；情绪从哪一档降到哪一档
- **防注水证明**：选 ①实用推进（落到可记账的状态库字段变更）或 ②羁绊加深（指向未来冲突章）之一并写出具体内容
- **主线侧面暗示**：那一处暗示是什么、指向哪条主线／哪张反派卡、第几章可能被兑现
- **连写计数与回归**：连写第 X/2 章；下一章以什么钩子切回哪条主线
