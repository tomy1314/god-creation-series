# 诗学规则包（小说内诗歌写作规范）
## 一、总则
1. 诗在小说中不是装饰，是功能件。每首诗必须有明确功能：言志、抒情、讽喻、应酬、谶语。
2. 写诗前先判断三件事：谁写的、写给谁看的、这首诗要完成什么叙事任务。
3. 不符合人物身份的诗，一律不写。武将不写婉约词，市井不写庙堂诗，儿童不写哲理诗。
4. 宁可少写，不可滥写。一卷之内，承担核心功能的诗不超过三首。
## 二、五类诗的功能与写法
### 1. 言志诗
- 触发条件：人物在重大抉择前、赴死前、表明立场时。
- 写法要求：直抒胸臆，不绕弯子，意象宏大（山河、日月、剑马、生死）。
- 禁忌：不写儿女情长，不写风花雪月。
- 范例结构：前两句写景/写势，后两句写志/写决。
### 2. 抒情诗
- 触发条件：情绪积压到无法用散文表达时，用诗做“情绪出口”。
- 写法要求：意象具体（一草一木、一酒一灯），不写抽象情绪词。
- 禁忌：不写“我好悲伤”“我心如刀割”这类直白句。
- 范例结构：全诗只写一个场景，情绪藏在场景里，不点破。
### 3. 讽喻诗
- 触发条件：政治斗争、文人交锋、公开表态。
- 写法要求：用典、双关、反语，表面写甲，实际骂乙。
- 禁忌：不直接点名骂人（会掉脑袋），必须藏一层。
- 范例结构：前两句写历史典故，后两句写当下现实，读者自己会对照。
### 4. 应酬诗
- 触发条件：文会、宴席、科举、贺寿、送别。
- 写法要求：工整、得体、有典故、有彩头，不需要真情实感。
- 禁忌：不出格、不冒犯、不冷场。
- 范例结构：四平八稳，春夏秋冬各一句，或者梅兰竹菊各一句。
### 5. 谶语诗
- 触发条件：道士、疯子、儿童、将死之人开口说话时。
- 写法要求：看似疯话/童谣/醉话，实则精准预言后文。
- 禁忌：不能说得太明白，必须让读者第一遍读不懂，后文揭晓时才恍然。
- 范例结构：四句民谣体，每句藏一个伏笔，全书结束时回收。
## 三、人物诗风对照表（写诗前必须查这张表）
| 人物 | 诗风 | 用词偏好 | 禁忌 |
|---|---|---|---|
| 主角 | 克制、偏执、有杀气 | 刀、血、路、夜 | 不写风花雪月 |
| 师父类 | 刻薄、通透、带讽刺 | 钱、命、药、卦 | 不写豪言壮语 |
| 文人型 | 工整、用典、藏锋芒 | 经史、典故、对仗 | 不写粗话 |
| 武将型 | 粗粝、直白、有血性 | 马、刀、酒、骨 | 不写婉约 |
| 市井型 | 俚俗、俏皮、带脏字 | 钱、饭、婆娘、命 | 不写文雅 |
| 道士型 | 玄虚、双关、藏谶语 | 云、鹤、卦、劫 | 不写大白话 |
| 疯癫型 | 颠倒、重复、藏真相 | 重复词、童谣体 | 不写完整逻辑 |
## 四、质量红线（违反即重写）
1. 禁止辞藻堆砌：一首诗里不能出现三个以上不承担功能的形容词。
2. 禁止放之四海而皆准：把诗里的地名、人名换掉还能成立，就是失败。
3. 禁止格律混乱：要么严格按格律写，要么明确写成古风/打油诗，不能半文半白。
4. 禁止人物错位：丫鬟不能写出士大夫的诗，武将不能写出闺阁词。
5. 禁止无功能诗：每首诗必须在后文有呼应（被引用、被评价、被应验、被反驳）。
## 五、写诗流程（WB 执行步骤）
1. 判断触发：当前场景是否属于五类诗的任何一类触发条件？不是则不写。
2. 查人物诗风表：谁写的？按他的诗风写。
3. 定功能：这首诗要完成什么叙事任务？言志/抒情/讽喻/应酬/谶语。
4. 写第一稿：先保证功能，再保证格律，最后润色。
5. 质量自检：过五条红线。不过则重写。
6. 埋呼应：这首诗在后文必须有一次呼应（引用/评价/应验/反驳），在细纲里标注。
