# 题材扩展包索引​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
本目录是题材扩展包目录。核心 skill（`SKILL.md`）保留通用机制，题材专属内容放在本目录。

## 1. 加载规则​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
1. 阶段 0 初始化时，AI 必须先确认题材，再加载对应扩展包。
2. 加载后，扩展包内容与核心 skill 合并生效；冲突时以核心 skill 的硬约束为准。
3. 未指定题材时，AI 不得自行选择，必须走「题材询问机制」。
4. 跨题材作品可加载多个扩展包，加载规则见 `SKILL.md`「混合题材处理」。
5. 运行环境无法读取扩展包时，降级为仅使用核心 skill，并提示用户「未加载题材包，风格可能不精准」。
6. 每个扩展包共 13 节：**§1–§4 商业层**（核心爽点与读者期待／常见毒点与避坑／力量或规则基线／专属套路公式），**§5–§13 文风层**（AI 身份具体化、意象系统、对话禁忌、世界观规则模板、爽点类型速查、人物语言指纹库、历史知识边界、有效扩写方向权重、生活化标准）。商业层在大纲、细纲阶段用（经 `project/genre-baseline.md` 一页摘要），文风层在写正文与审正文阶段用。

### 跨频题材处理规则​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
跨频题材天然双线并行，加载时需明确：
1. **主题材**与**辅题材**的关系（悬疑主线/情感副线，或反之）。
2. 冲突时以**主题材**为准：主题材决定世界底层规则、爽点类型、语言基调。
3. 辅题材只做风味补充，不改变底层规则。
4. 双线节点需交织，不能各写各的。

## 3. 用户自行输入题材​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
用户输入清单外题材时：
1. AI 先按「核心特征 + 意象系统 + 爽点类型」补充归类。
2. 归类到男频 / 女频 / 跨频之一。
3. 再询问是否添加辅题材，给推荐 + 理由。
4. 若题材过新、无法归类，按最接近的现有题材加载，并提示用户。

## 4. 混合题材加载​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
1. 先确认主题材和辅题材。
2. 加载对应扩展包组合。
3. 冲突时以主题材为准。
4. 主题材决定：世界底层规则、读者预期、爽点类型、语言基调；辅题材只做风味补充，不改变底层规则。
5. 禁止「两个题材各写一半」的拼贴式融合。
