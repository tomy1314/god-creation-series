# 首发门禁 · 引擎模式确认（0a 之前）

> 本文件是【第一道门禁】的唯一权威文本，受 `references/process-gates.md` 总则约束。
> 触发时机：用户交出种子（大纲／设定／片段／一句话梗概）之后，**0a 之前**。
> 与本文冲突的任何表述，以本文为准；本文与 `process-gates.md` 冲突，以 `process-gates.md` 为准。

## 1. 执行顺序（同一轮内完成，不得拆轮）

1. 先输出《阶段状态表》（14 阶，全部「未完成」，见 `process-gates.md` 附表）。
2. 紧接着**逐字**输出下方【模板原文】，不得改写、不得增删条目、不得先做诊断。
3. 停止。除模板外不输出任何分析、题材建议、人物设想、正文片段。

**禁止：** 先谈题材、先给方案、先问别的、把三选一混进别的问卷、替用户选。

## 2. 模板原文（逐字输出，含 emoji 与加粗）

```
📥 **已收到您的种子。在正式启动诊断之前，请先确认本书的【创作引擎模式】：**
**1. 💥 爽文模式（Web Mode）**：
快节奏、强冲突、黄金三章、卡点留钩。台词配比严控（8%-55%），主角必须有强烈的内驱力与爽点释放。
**2. 📖 传统严肃文学模式（Literary Mode）**：
重质感、重铺垫、散文化叙事。允许长线伏笔与时代背景描写，放宽台词配比（5%-65%）与单章字数（2000-8000字）限制。
**3. 🎬 二合一模式（Cinematic Mode）**：
兼顾网文的节奏感（章末留悬念）与文学的厚重感（重画面与群像调度）。折中校验逻辑。
**请回复数字（1 / 2 / 3）确定模式。**
```

## 3. 路由表（用户回复后执行）

| 回复 | `work_mode` | 必须原样告知用户的话 | 校验口径 |
|---|---|---|---|
| `1` | `web` | 已启用爽文模式，后续 `guard.py` 将采用严格红线校验。 | 2000–5000 字／台词 8%–55%／旁白 ≤12%／拦提前收尾 |
| `2` | `literary` | 已启用传统文学模式，校验限制已全面放宽。 | 2000–8000 字／台词 5%–65%／旁白 ≤25%／不拦提前收尾；7.5 双栖豁免生效 |
| `3` | `cinematic` | 已启用二合一模式，后续将按折中标准校验。 | 暂沿用 `web` 基线（待单独标定），7.5 不豁免 |

## 4. 落盘规则（不违反 0c-0 schema 门禁）

`work_mode` 一经本门禁锁定，即为**本书定稿值**，后续不得由 AI 擅改。

| 项目状态 | 写到哪里 |
|---|---|
| **续建／返工**：`project/state-schema.md` 已存在 | 直接写入该文件的 `work_mode` 字段，并在《阶段回执》注明「首发门禁锁定」 |
| **新书**：schema 尚未建立（0c-0 之前禁止创建生效 schema） | 写入 `project/state-schema.draft.md` 的 `work_mode`；同时在 `project/constraints/author-decisions.md` 追加一条 `AD-ENGINE`：锁定值｜用户原话（1/2/3）｜锁定时间。0c-0 建生效 schema 时**原样带入，不得改写** |

告知语之后追加一句口径说明（只在新书时说）：「已记入 draft 与作者口径，0c-0 建 schema 时原样带入。」

## 5. 防呆与无回复处理

1. **匹配规则**：去空白、去全角空格后，**整段恰好等于** `1`、`2`、`3` 之一，才算通过。`1.`、`1 爽文`、`1和2`、`其他` 一律不通过。
2. **未回复数字**（发了新剧情、新设定、问别的问题、说「随便」「你定」）→ **只**输出下面这一句，不加诊断、不写正文、不进入 0a：
   > 为了确保后续生成的节奏符合您的期望，请先回复数字（1/2/3）选定创作模式哦。
   紧随其后复述三行极简选项（`1 爽文 / 2 传统文学 / 3 二合一`），不复述整段模板。
3. **连续拦截**：不设次数上限，也不自动选。用户第 3 次仍未选，仍按第 2 条处理。
4. **唯一例外**：作者明确说出授权语（如「就按你说的定」「你替我选」）时，按 `1`（`web`）落盘，并在 `AD-ENGINE` 记「作者授权默认 web，原话：___」。除此之外，AI 不得代选。
5. **超时**：对话式交互无法计时，本门禁不设自动超时；无回复即停留在此，不得推进。

## 6. 通过之后

输出《阶段回执》（阶段＝首发门禁｜要求＝回复 1/2/3｜证据＝用户原话数字｜状态＝完成｜缺什么＝无｜等待的确认口令＝题材规模确认），随后进入 **0a 题材与规模确认**。

> 注意：0a 负责题材与规模，**不再重复问引擎模式**；0a+ 的主编诊断在此之后进行。若作者在 0a 之后想改模式，必须**重开本门禁**并重新落盘，改动从下一章生效。
