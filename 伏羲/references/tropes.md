# 女频爆款叙事模组库（v1.8.2 自 workflow.md 外移）

> 供 0a+ 主编诊断调用。当用户提供女频种子时，AI 的主编诊断可优先匹配以下 3 个近期高热度模组。

**模组 1：【清醒追妻火葬场】（现言/情绪流）**
- **核心钩子**：用“极度克制的清醒”对抗“周遭善意包裹的拿捏”。
- **剧情配置**：开篇制造极度憋屈的压迫感（如领证被放鸽子、全家隐瞒某事），但女主不哭不闹。她的应对是：取消婚礼、整理账单、拿回属于自己的利益、重启事业。
- **主编话术**：“老板，如果走这个方向，我们不走歇斯底里的对撕路线，而是‘冷处理’。爽点在于‘事实自己说话’，渣男在女主的理智反杀下追悔莫及。”
- **驱动/结构**：情感拉扯流 + 多线交织。

**模组 2：【强内核数字打脸】（都市/家庭/现实）**
- **核心钩子**：开头用极具冲击力的反差数字（如：年薪百万拿不出18万救命钱），快速拉升矛盾量级。
- **剧情配置**：主角拒绝精神内耗，主打“强执行力”（收集证据、对账、见律师、查资产）。矛盾高度集中在饭桌、病房等“熟人场”，让打脸充满窒息感。
- **主编话术**：“老板，这个模组需要主角智商武力双在线，如果偏向写家庭伦理的压迫与反击，这套强内核模组绝对能留住读者。”
- **驱动/结构**：智斗博弈流 + 线性顺叙。

**模组 3：【蛰伏延时复仇】（古言/权谋宅斗）**
- **核心钩子**：开篇点明最极端的背叛（如：丈夫临终要把私生子交给她养老），但女主不即刻发作。
- **剧情配置**：女主前期在不动声色中收集核心证据（账目、契纸、人脉），将每一次吃亏折换成实体资产。在反派以为稳操胜券的最后关头，甩出证据，一招绝杀。
- **主编话术**：“老板，如果是古风宅斗，这套‘延时复仇’能极大降低前期承压的憋屈感。读者知道女主一定会赢，只是耐心等她落子。”
- **驱动/结构**：苟道稳健流 + 倒叙（伏笔埋设二十年）。

**使用规则**：AI 在 0a+ 诊断时，必须先提取种子特征。若种子特征与某一模组匹配，推荐方案 A 套用该模组并说明爽点逻辑；若种子不属于三类模组范畴（如甜宠、种田），按常规诊断出方案，不强制套用。
