## 逐句台词确认模式​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
### 触发条件​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
- **大循环模式**：默认关闭，用户说「开启台词确认」「逐句确认台词」「台词我来定」「每句台词问我」时手动开启。
- **小循环模式**：默认启用，用户可用「本章自动」退出。
- **自动续写模式**：改为「AI 代选 + 事后逐句改」，不逐句暂停。
- **精修模式**：进入时询问用户是否逐句改。
### 模式适配策略​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
| 场景 | 模式 | 逐句确认 |
|------|------|---------|
| 关键章节（高潮、反转、伏笔回收、重要对话） | 小循环 | 默认启用 |
| 过渡章节（主线推进、日常、铺垫） | 大循环 | 手动开启 |
| 自动续写 | 大循环 | AI 代选 + 事后逐句改 |
### 核心规则​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
1. 只询问**角色说出口的台词**。
   - 不询问：旁白、环境描写、动作描写、心理描写、内心独白、心声、留白、沉默、省略号。
   - 若心声写成引号直接说出，则询问；若写成“他心想……”，不询问。
2. 每到一句台词，暂停正文生成，先输出【台词提案卡】，等用户回复后再嵌入正文，继续下一段。
3. 推荐台词必须基于：
   - 角色档案：性格标签、语言指纹、当前情绪、当前目标、恐惧、秘密、关键关系；
   - 场景功能：推进情节 / 揭示性格 / 制造冲突 / 埋设伏笔 / 回收伏笔；
   - 当前信息释放约束：本章只揭示 1 个关键信息，其余用悬念勾住。
4. 推荐固定 4 个，每个标注风格 + 潜台词。
5. 用户可自由输入，**用户输入优先级最高**，AI 不擅自改写。
   - 若用户输入与角色档案或世界观硬设定冲突，AI 只提示，不擅自修改。
   - **语言指纹冲突时**：不改 `characters.md` 中该角色的语言指纹（语言指纹是角色固有特征，每人固定 2-3 个）。只在 `dialogue_log.md` 对应条目标注「用户确认偏离」。除非用户明确说「这个角色以后说话就这样」，才改语言指纹。
   - 若用户输入涉及内容安全硬约束，AI 拒绝并提示调整。
6. 用户可选操作：
   - 选推荐：`A` / `B` / `C` / `D`
   - 自己写：直接输入台词内容
   - 修改推荐：`改A：……`
   - 跳过这句：`跳过`（AI 改为动作、留白或沉默）
   - 本场景自动：`本场景自动`
   - 本章自动：`本章自动`
   - 回改某句：`回改第X句`（只替换该句，并重新评估影响）
7. **批量确认 + 事后单句回改**：
   - 允许用户说「本场景全部用推荐 A」「本章自动」。
   - 批量确认后，用户可随时说「回改第 X 句」，AI 只替换该句。
   - 替换后重新评估该句对后续台词、状态库、滚动摘要的影响。
8. **台词确认轮**：
   - 逐句确认模式下，单轮可能不足 2000 字。
   - 新增“台词确认轮”概念，字数**按章累计，不按轮累计**。
   - 单章字数按引擎基线执行（web 2000–5000；**`literary` 2000–8000，不受本条 5000 上限约束**），但可分多个确认轮完成。（本条是对「约束」章节“每轮正文不少于 2000 字”的显式例外；C2-2 补双栖豁免）
9. **每章末自查台词与前文联系**（4 项）：
   - [ ] 角色语气与前文一致（对照 `characters.md` 语言指纹 + `dialogue_log.md`）
   - [ ] 台词信息与已有事实不矛盾（对照状态库、时间线）
   - [ ] 未误用 / 提前回收未到期伏笔（对照 `foreshadowing.md`）
   - [ ] 台词未与已确认历史台词重复或雷同（对照 `dialogue_log.md`）
10. **对话质量评分照旧（含重写边界）**：
    - 每章至少抽取 3 组关键对话评分。
    - **AI 推荐 / 代选的台词**：任何维度低于 3 分或均分低于 3.0，仍按「对话质量评分」章节规则自动标记「待重写」并自动重写，输出重写理由。
    - **用户自己输入的台词**：评分低时只提示用户，由用户决定是否重写，AI 不自动改写。
    - 重写/提示后仍输出【对话质量报告】。

### 对话禁忌（反捧哏 · 内容层）

> 与「题材对话禁忌」分工：题材级管"这类词/这类称呼能不能出口"（见 `init-and-genre.md`）；本条管"对话是不是捧哏式接话"，属内容层，两者各判各的。

**【反捧哏规则】** 对话不能变成"你一句我一句"的对仗式接话（如"你短""你的也短"）。
- 废话必须是**答非所问**或**跑题**，不是"为了接话而接话"。接得越工整越假。
- 对话必须带**潜台词**或**动作打断**；两句在同一逻辑层你来我往、越接越齐 = 捧哏式抬杠，删一组或改成错位回答。
- 判定：删掉这段对话，两人的利害／关系张力有无变化？没变化 → 是捧哏，删；有变化 → 有效对话。
- 反例（禁止）："你这根短。""尺也有短的。""那也不能差这么多。""差多少算多？"
- 正例（允许）："你这根短。""……今儿日头毒。"（答非所问，但把话头堵死了）

**【空转熔断＋动作锚定（v1.8.4 增 · 与反捧哏同向，不替代）】**
- **熔断测试**：每 3 个对话回合，抽掉中间那一回合——故事无损 → 空转，判 ✗，强制删减。答非所问的合法废话（上面那个"日头毒"）**不计入**熔断回合数。
- **动作锚定**：斗嘴必须伴随至少 1 个有目的的物理动作（边跑边骂、边数钱边挤兑、边收碗边顶嘴），禁止两人静止站着纯聊。
- **场景节流**：废话只在 `#日常`／`#缓冲` 场景豁免；`#危机`／`#战斗` 严禁无效废话，台词极度精简（占比档见 workflow.md 细纲第 15 列）。

### 台词提案卡格式​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
```
【台词提案 · 第X章 · 第Y句】
角色：XXX
场景：……（一句上下文）
功能：……（推进情节 / 揭示性格 / 制造冲突 / 埋设伏笔 / 回收伏笔）
角色当前状态：情绪…… / 目标…… / 对说话对象的态度……
上一句为什么说：场景功能…… / 角色动机…… / 伏笔信息……（小循环模式下必填；大循环模式可省略）
推荐：
A. “……”（风格：直接/试探；潜台词：……）
B. “……”（风格：回避/防御；潜台词：……）
C. “……”（风格：攻击/挑衅；潜台词：……）
D. “……”（风格：沉默/转移话题；潜台词：……）
请选择：A / B / C / D / 自行输入 / 跳过 / 本场景自动 / 本章自动
```
### 正文输出方式​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
逐句确认模式下，正文按“片段”推进：
```
【正文片段 · 第X章 · 场景1】……叙述……[待确认台词：角色XXX]
```
用户确认后：
```
【已嵌入】
……叙述……
XXX 说完，把杯子放下。
“用户确认或输入的台词。”
……继续叙述……[下一句待确认台词：角色YYY]
```
本示例仅为确认环节的展示格式，最终正文必须遵循台词排版规范，禁止「角色名：台词」格式。
本章所有台词确认完毕后，再输出完整章节正文与校验报告。正文排版遵循「台词排版规范」。

### 与小循环模式的兼容​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
- 小循环模式下逐句确认**默认启用**。
- 每句台词确认前，必须提醒用户：**上一句角色为什么说这个台词**。
- “为什么”拆成三个维度：
| 维度 | 提醒内容 |
|------|---------|
| 场景功能 | 这句话在场景里推进什么、隐藏什么、暴露什么 |
| 角色动机 | 该角色当前欲望/恐惧/秘密如何驱动这句话 |
| 伏笔/信息 | 这句话是否在埋设或回收伏笔，是否释放了关键信息 |
### 与自动续写模式的兼容​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
- 自动续写模式下，逐句确认改为「AI 先按角色档案代选，用户事后可逐句改」。
- 事后逐句改时：
  - AI 先评估该句是否改变剧情走向、人物关系、伏笔状态。
  - 若不变：只替换台词，更新对话评分。
  - 若变：标记受影响章节，对该章节对应的状态库与摘要条目登记「待重写标记」（**不物理回滚**——状态库为覆盖式写盘、保留历史），再按新台词重新推进，并登记变更。
- 自动续写模式仍须遵守自动续写「暂停点」规则（滚动摘要合并、逻辑硬校验重写、伏笔长期未回收时暂停）。
### 与精修模式的兼容​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
- 进入精修模式时，AI 必须询问用户：「本章是否需要逐句改台词？」
- 用户选是：在精修流程中插入逐句台词确认；精修诊断、精修方案、精修对照说明仍照常输出。
- 用户选否：按普通精修流程执行。
### 持久化​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
- 新增 `dialogue_log.md`，记录：条目 ID、章节/场景/句序、角色、上下文功能、4 个推荐及标注、用户选择/输入、最终台词、对话评分、回改记录、是否影响状态库/摘要、状态（已确认/待重写/已核销）。
- `characters.md` 新增“语言指纹”列，只存最近 3 条或关键条目的 ID / 锚点，不存全文。
- 权威文件清单登记与字段表已同步至 `references/progress-tracking.md` 第 8 节、`references/world-consistency.md` 第 1 节（语言指纹列）与第 5 节（完整字段表）。
## 台词排版规范​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
### 总原则​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
> 本 skill 生成的始终是**小说**，不是剧本。台词独立成行是排版手段，服务于小说阅读体验，不得演变成剧本格式。
> 未来若接入剧本 skill，由剧本 skill 负责剧本格式；本 skill 不承担剧本输出。
### 基本格式​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
```
张三放下杯子，声音压得很低。
“你确定要这么做？”
李四没看他。
“没有别的选择。”
```
- 角色说出口的台词独立成段。
- 引号保留，与中文小说惯例一致。
- 说话人靠动作、称呼、语言指纹带出，不靠剧本式“角色名：台词”。
### 禁止的写法​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
```
张三：你确定要这么做？
李四：没有别的选择。
```
这是剧本格式，**本 skill 禁止**。留给未来的剧本 skill。
### 独立成段范围​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
| 内容 | 是否独立成段 |
|------|------------|
| 角色说出口的台词 | 是 |
| 间接引语、转述 | 否 |
| 心声、内心独白 | 否（用斜体或单独格式） |
| 留白、沉默、省略号 | 否 |
### 说话人标注优先级​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
| 优先级 | 方式 | 例子 |
|--------|------|------|
| 1 | 动作前置 | `张三放下杯子。` → `“你确定？”` |
| 2 | 动作后置 | `“你确定？”` → `张三放下杯子。` |
| 3 | 称呼对方 | `“你确定？”张三看着李四。` |
| 4 | 语言指纹 | 靠口头禅、语气区分，不加“说” |
| 5 | 直接标注 | `张三说：“你确定？”`（最后手段，少用） |
> 纯“某某说”每章不超过 3-5 次。
### 连续对话处理​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌
两人对话可交替省略说话人，靠语言指纹区分：
```
“你确定要这么做？”
“没有别的选择。”
“她会恨你。”
“那就恨吧。”
```
三人以上对话，每 2-3 句必须补一次动作或称呼。

## 方言与口音控制阀​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌

本机制用于增加角色生活感与辨识度，但绝不能造成阅读障碍或题材串味。

### 1. 方言使用分级（上限为 L2）​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌

- **L1 词汇点缀（最推荐）**：仅使用大众熟知的标志性方言词汇（如东北话「得瑟」、四川话「巴适」）。
- **L2 语气助词**：适度使用方言特有的句末语气词（如「嘛」「咧」「噻」）。
- **L3 语序句式（极其谨慎）**：除非极其自然，否则尽量少用倒装句。
- **严禁 L4**：禁止用拼音代替汉字（如「猴赛雷」），禁止大段让非本地读者完全看不懂的方言对白。
- **例外**：网络语气词/网络口语不受 L1–L4 分级约束，非攻击性即可保留（见「审稿口径纪律·人味优先」）。

### 2. 加注原则​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌

生僻的方言词汇，必须在首次出现时用括号进行即时注释。例如：这事儿办得真「老卵」（厉害）。

### 3. 题材红线​‌‍‌‌‌​‌​​​‌​‌‌​‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​‌‌‌‌​​‌​​​‌‌‌‌​‌​​‌‌​‌​​​‌‌‌​​‌‌‌‌​‌‌‌​​‌​‌‌​​​‌‌​‌‌​‌‌​​​​‌‌‌​‌​​​‌​‌‌​​​‌‌​‌​​​​‌

- **适用**：都市、年代文、种田文、悬疑（有明确地域背景时）。
- **绝对禁用**：仙侠、玄幻、西幻、科幻（除非角色设定中有明确的「穿越者」或「特定星球口音」）。古代题材禁用现代方言。
