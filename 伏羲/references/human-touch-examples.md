# human-touch-examples.md · 人味与防贫嘴 · 正反例库（v1.8.4 新增）

> **本文件是冷数据**：常态写作、细纲、对账**都不读它**（0 成本）。
> **只在两种时机读**：① 落地闸判 ✗ 需要改句时；② 作者对某条判据有异议、要看「为什么」时。
> 条文（判据本身）在 `prose-rules.md`（G1／T3）、`dialogue.md`（熔断）、`workflow.md`（第 15 列）里，**这里只放例子**。
> 例子一律为说明判定方式而造，**换书不得沿用人名、地点、道具**。

## 一、生理破绽（女娲字段 · 只判有没有，不判深意）

| | 内容 | 判定 |
|---|---|---|
| ❌ 有功能 | 「他紧张地握紧了刀柄」「她不安地攥紧衣角」 | 动作在传递情绪 → 是**表演**，不是破绽 |
| ❌ 有寓意 | 「他一遍遍摸着母亲留下的铜板」 | 带象征 → 后文会被要求回收，破坏「不回收」前提 |
| ❌ 太干净 | 「他喝了一口茶」 | 无特异性，放谁身上都成立 → 不是这个人的破绽 |
| ✅ 合格 | 「报数之前，他把袖口往里卷了半圈——卷完才发现没必要。」 | 无意义、无功能、只有他有 |
| ✅ 合格 | 「掌柜的一边说话，一边拿指甲刮柜台上一块漆；漆早就没了，他还在刮。」 | 纯惯性，与剧情零关系，但人立住了 |

**判据落点**：这一场他紧张／撒谎／被盯着时，那个动作**出现了吗**？没出现＝人味缺项（提示，不判 ✗）；出现了但**被解释、被赋予意义、被后文回收**＝判 ✗。

## 二、防御机制（被逼问时的搪塞）

| | 内容 | 判定 |
|---|---|---|
| ❌ 工整辩解 | 「我昨天没去码头，是因为船晚了；船晚是因为上游下了三天雨。」 | 三层因果、句句收得住 → 这是供词，不是人话 |
| ❌ 全知认罪 | 「是我做的，我认。」 | 太顺、太快，缺少抵抗的过程 |
| ✅ 打岔扯远 | 「码头？码头那帮人现在连饭都吃不上。你吃过饭没有？」 | 用无关的家常把话头顶回去 |
| ✅ 反问 | 「你问这个干什么？你先说说你昨天在哪。」 | 抢回主动权 |
| ✅ 装听不懂 | 「船？什么船。我们这儿只有筏子。」 | 抠字眼拖延 |
| ✅ 沉默 | （他不说话，把碗端起来喝，喝完了把碗放下，还是不说话。） | 沉默也是防御，但要写成动作，不能写成「他沉默了」 |
| ✅ 反常话多 | 「我不认识他，真不认识，我连他姓什么都不知道，你别这么看我——我真不认识。」 | 越解释越乱，心虚外露 |

**判据落点**：这句台词像**被逼急了的人**，还是像**作者替他写好的答案**？后者判 ✗。

## 三、开篇（G1 判据三 · 全章前 50 字）

| | 内容 | 判定 |
|---|---|---|
| ❌ 天气景物 | 「天刚蒙蒙亮，雾气还没散，街上一个人也没有。」 | 前 50 字写景，无人在场 → ✗ |
| ❌ 报户口 | 「陈默，三十二岁，城南修车铺的老板。」 | 档案句 → ✗ |
| ❌ 分解特写 | 「他的指节因用力而发白，青筋在薄皮下微微跳动。」 | 身体细节分解，撞「叙事呼吸三条」→ ✗ |
| ✅ 合格 | 「老陈把第三根辐条拧断的时候，天还没亮透。」 | 谁＋在干什么，景随事出，且带损耗 |
| ✅ 合格 | 「娘把那半碗粥推过来，自己端起空的喝了一口。」 | 动作即关系，无一句解释 |

**判据落点**：第一句里**有没有一个人的手在动**？没有 → ✗。「在哪」不作要求（本场前三段内落地即可）。

## 四、章末（G1 判据四 · 禁景观禁抒情）

| | 内容 | 判定 |
|---|---|---|
| ❌ 自然景观 | 「风从巷口吹过来，卷起地上的纸钱。」 | 章末写景 → ✗（卷末章除外） |
| ❌ 总结心情 | 「他知道，有些东西再也回不去了。」 | 替读者总结 → ✗ |
| ❌ 抒情升华 | 「这一夜，注定无人入眠。」 | 套话＋升华 → ✗ |
| ✅ 没干完的事 | 「水开了。他没去关。」 | 停在一个未完成的动作上 |
| ✅ 没干完的事 | 「线穿到第三回，还是没穿进针眼。」 | 琐事悬着，读者自己知道出事了 |
| ✅ 没干完的事 | 「他应了一声，转身去够门后的扁担——话还没说完。」 | 被打断即收 |

**判据落点**：最后一句**能不能配一句"他知道……"的旁白**？能配上 → 说明你在抒情，判 ✗。

## 五、金句三连（T3）

| | 三句原文 | 判定 |
|---|---|---|
| ❌ | 「穷不可怕，怕的是认命。」「人活着，总得有点念想。」「这世道，谁不是咬着牙过。」 | 三句遮住上下文全能当签名 → ✗ |
| ✅ | 「穷不可怕，怕的是认命。」「……你把那半袋米先还我。」「我不是那个意思。」 | 第二句被打断／降格 → 过 |

**判定动作**：遮住上下文，逐句问「能单独当签名吗」。**三句全能 → ✗**；两句能、一句不能 → 过。

## 六、空转熔断（每 3 回合抽中间一回合）

原对话（三回合）：

> A：「这货不对。」
> B：「怎么不对？」
> A：「你自己看。」

抽掉中间那一回合：

> A：「这货不对。」
> A：「你自己看。」

**故事无损**（信息量不变，关系张力不变）→ 中间那回合是**空转** → ✗，删。

反例（合法废话，不计入熔断）：

> A：「你这根短。」
> B：「……今儿日头毒。」

抽掉 B 那句，A 的试探**没有得到回应**，关系张力变了 → 不是空转，保留。

## 七、动作锚定

| | 内容 | 判定 |
|---|---|---|
| ❌ 静止对聊 | 两个人站在院当中，你一句我一句说了两百字 | 无动作 → ✗ |
| ✅ | 「他一边把麻袋往驴背上甩，一边骂；骂到第三句，麻袋掉下来，他捡起来再骂。」 | 骂与干活同步，动作本身也在推剧情 |
| ✅ | 「她数钱的手没停，嘴上已经在挤兑人；数到第七张，手停了——钱不够。」 | 斗嘴中途被物理事件打断，一句顶三句 |

**判据落点**：这段对话删掉所有动作提示语，还剩不剩画面？不剩 → ✗。

## 八、场景标签三值速查（写细纲时看这一格就够）

`类型｜#废话档｜#情绪档` → 例 `对峙｜#交涉｜#压`

| 废话档 | 允许废话 | 台词占比（文戏） |
|---|---|---|
| `#日常`／`#缓冲` | 允许，可打岔扯远 | 30%-50%（废话 ≤30%） |
| `#交涉` | 允许少量试探，≤3 回合 | 25%-40% |
| `#危机` | **严禁**无效废话 | **≤20%** |
| `#战斗` | **严禁** | **≤10%** |

| 情绪档 | 含义 | 呼吸阀计数 |
|---|---|---|
| `#爆` | 高强度爽点／高潮 | 连 3 章 → 调月老 |
| `#压` | 压抑／低谷 | 连 5 章 → 调月老 |
| `#缓` | 缓冲／过渡 | 计数归零 |

> 计数是**字符串连加**，不是感觉判断。新卷首章视为呼吸阀必触发。
